# Aprende+

Repositório preparado para publicar o Aprende+ como PWA no GitHub Pages.

## Arquivos
- `index.html` — aplicativo
- `manifest.webmanifest` — informações de instalação do app
- `sw.js` — Service Worker para cache/offline básico
- `icons/icon-192.png` — ícone PWA 192×192
- `icons/icon-512.png` — ícone PWA 512×512

## GitHub Pages
1. Envie todos os arquivos para a raiz do repositório.
2. Mantenha a pasta `icons` e os dois PNGs dentro dela.
3. Em **Settings → Pages**, use **Deploy from a branch**, branch `main`, pasta `/ (root)`.
4. Abra o endereço publicado em HTTPS no Chrome.
5. Use **Instalar aplicativo** ou **Adicionar à tela inicial**.
